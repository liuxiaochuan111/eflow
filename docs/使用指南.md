## 表单清单管理

### 查看表单列表

访问表单清单页面可以看到所有已创建的表单：

- **表单名称** - 表单的显示名称
- **表单ID** - 表单的唯一标识
- **创建时间** - 表单的创建时间
- **操作** - 编辑和删除按钮

### 创建新表单

1. 点击右上角的"新增表单"按钮
2. 系统会自动创建一个空白表单并进入编排界面

### 编辑表单

1. 在表单列表中点击"编辑"按钮
2. 进入编排界面进行修改

### 删除表单

1. 在表单列表中点击"删除"按钮
2. 确认删除操作

## 编排表单

### 编排界面布局

编排界面分为三个区域：

- **左侧面板** - 组件清单和数据结构
- **中间画布** - 表单编排区域
- **右侧面板** - 属性和事件配置

### 拖拽添加组件

1. 在左侧面板选择"容器"或"表单项"标签
2. 将需要的组件拖拽到中间画布
3. 组件会自动添加到表单中

### 组件层级关系

- 容器组件可以包含其他容器或表单项
- 表单项是叶子节点，不能包含其他组件
- Row 容器支持栅格布局，可以设置 span 属性

### 删除组件

选中组件后按 Delete 键或点击删除按钮

### 调整组件顺序

拖拽组件可以调整其在父容器中的位置

## 属性配置

### 表单项属性

每个表单项都有以下基本属性：

- **model** - 字段名称，用于数据绑定
- **label** - 标签文本
- **required** - 是否必填
- **display** - 是否显示
- **span** - 栅格占位（仅 Row 中生效）

### 组件属性

不同组件有特定的属性：

#### Input 输入框
- `placeholder` - 占位文本
- `clearable` - 是否可清空
- `maxlength` - 最大长度
- `showWordLimit` - 显示字数统计
- `type` - 输入框类型（text/password/number/email/url）
- `prefixIcon` - 前缀图标

#### Select 选择器
- `placeholder` - 占位文本
- `clearable` - 是否可清空
- `multiple` - 是否多选
- `filterable` - 是否可筛选
- `remote` - 是否远程搜索

#### DatePicker 日期选择器
- `type` - 选择器类型（date/datetime/daterange/month/year）
- `placeholder` - 占位文本
- `format` - 显示格式
- `valueFormat` - 绑定值格式

## 事件绑定

### 事件类型

每个表单项支持不同的事件：

- **change** - 值改变时触发
- **input** - 输入时触发
- **blur** - 失去焦点时触发
- **focus** - 获得焦点时触发
- **clear** - 清空时触发

### 事件动作

#### 1. 设置属性

设置指定控件的属性值：

- **目标控件** - 选择要操作的控件
- **属性名** - 选择要设置的属性
  - `display` - 显示/隐藏
  - `disabled` - 禁用/启用
  - `required` - 必填/非必填
  - `value` - 值
  - `placeholder` - 占位文本
- **属性值** - 设置的值

示例：当选择器值改变时，隐藏另一个输入框

#### 2. 显示控件

快捷显示指定控件

#### 3. 隐藏控件

快捷隐藏指定控件

#### 4. 启用控件

快捷启用指定控件

#### 5. 禁用控件

快捷禁用指定控件

#### 6. 设置值

设置指定控件的值，支持表达式：

```
formData.model1 + 100
State.user.name
```

#### 7. 数据映射

从 State 或表单数据映射数据到指定控件：

- **目标控件** - 接收数据的控件
- **数据源** - 数据来源
  - `State.model1` - 从 State 获取
  - `formData.model2` - 从表单数据获取

#### 8. 执行函数

执行预定义的自定义函数：

- **函数名称** - 函数名
- **参数** - 函数参数（JSON 格式）

#### 9. 重置值

重置指定控件的值为初始值

#### 10. 清除校验

清除指定控件的校验结果

### 事件配置示例

场景：用户选择"其他"时显示输入框

1. 选择 Select 组件
2. 在事件面板添加 change 事件
3. 添加动作：
   - 类型：设置属性
   - 目标：备注输入框
   - 属性：display
   - 值：`formData.type === 'other'`

## 使用 FormBuilder 组件

### 基础用法

```vue
<template>
  <FormBuilder
    v-model="formData"
    :schema="formSchema"
  />
</template>

<script setup>
import { ref } from 'vue'
import FormBuilder from '@/components/builder/FormBuilder.vue'

const formData = ref({})
const formSchema = ref({
  type: 'Container',
  component: 'Container',
  display: true,
  options: {},
  children: [{
    type: 'Container',
    component: 'Form',
    display: true,
    options: {},
    children: [{
      type: 'FormItem',
      component: 'Input',
      model: 'name',
      label: '姓名',
      display: true,
      options: {
        placeholder: '请输入姓名'
      }
    }]
  }]
})
</script>
```

### Props

| 参数 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| modelValue | 表单数据 | object | {} |
| schema | 表单 Schema | SchemaTree | - |
| eventConfig | 事件配置 | EventConfig | {} |
| isBuild | 是否为编排模式 | boolean | false |
| configData | 补充属性配置 | object | {} |
| compConfig | 组件映射配置 | object | {} |
| customFuncs | 自定义函数 | object | {} |
| State | 外部状态对象 | object | {} |
| skipModels | 跳过渲染的节点 | string[] | [] |
| pageUrl | 表单ID（用于加载schema） | string | - |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 表单数据变化 | (data: object) |
| renderEnd | 表单渲染完成 | - |
| change | 字段值变化 | (field: string, value: any) |

### Expose

| 方法名 | 说明 | 类型 |
|--------|------|------|
| validate | 表单校验 | () => Promise<boolean> |
| clearValidate | 清除校验 | () => void |
| setSchemaByConfig | 批量设置属性 | (config: object, prop: string) => void |
| getFormData | 获取表单数据 | () => object |

### 事件联动示例

```vue
<template>
  <FormBuilder
    v-model="formData"
    :schema="formSchema"
    :event-config="eventConfig"
    :custom-funcs="customFuncs"
    :state="appState"
  />
</template>

<script setup>
import { ref } from 'vue'

const formData = ref({})
const appState = ref({
  user: { name: 'John', age: 25 }
})

const customFuncs = {
  calculatePrice: (quantity, unitPrice) => {
    return quantity * unitPrice
  },
  submitForm: (data) => {
    console.log('提交表单:', data)
  }
}

const eventConfig = ref({
  quantity: {
    change: [{
      id: 'evt_1',
      target: 'totalPrice',
      method: 'setValue',
      props: {
        value: 'customFuncs.calculatePrice(formData.quantity, formData.unitPrice)'
      }
    }]
  }
})
</script>
```

## 常见问题

### Q: 如何添加自定义组件？

A: 在 `configs/form-items.ts` 中添加组件配置，然后创建对应的渲染组件。

### Q: 如何实现复杂的表单验证？

A: 使用 FormBuilder 的 `validate` 方法进行表单验证，或在组件的 `validator` 属性中定义验证规则。

### Q: 事件联动中的表达式如何编写？

A: 支持简单的 JavaScript 表达式：
- `formData.model1` - 引用表单字段
- `State.user.name` - 引用状态对象
- `formData.model1 + 100` - 表达式计算

### Q: 如何动态修改表单结构？

A: 使用 `setSchemaByConfig` 方法批量修改节点属性，或直接修改 schema 对象。
