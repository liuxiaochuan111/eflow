## 常用属性速查

### 通用属性
所有组件都支持的属性：
- `disabled` - 禁用
- `size` - 尺寸（large/default/small）
- `placeholder` - 占位文本（输入类）
- `clearable` - 可清空（选择类）

### 验证属性
输入类组件通用：
- `validateEvent` - 触发验证
- `readonly` - 只读
- `autofocus` - 自动聚焦

### 样式属性
所有组件通用：
- `className` - 自定义类名
- `style` - 内联样式
- `width` - 宽度

### 数据属性
列表类组件：
- `options` - 选项数据（JSON格式）
- `props` - 配置选项（JSON格式）

## 属性值类型说明

### String 类型
- 普通文本值
- 使用 `Input` 组件配置

### Boolean 类型
- 开关值
- 使用 `Switch` 组件配置

### Number 类型
- 数字值
- 使用 `InputNumber` 组件配置
- 支持 min、max、step 约束

### Enum 类型
- 枚举值（有预定义选项）
- 使用 `Select` 组件配置

### Array/Object 类型
- 复杂数据结构
- 使用 `Input` 组件配置（JSON格式）

## 配置示例

### 示例1：必填的用户名输入框
```json
{
  "type": "FormItem",
  "component": "Input",
  "model": "username",
  "label": "用户名",
  "required": true,
  "options": {
    "placeholder": "请输入用户名",
    "clearable": true,
    "maxlength": 20,
    "showWordLimit": true,
    "prefixIcon": "User"
  }
}
```

### 示例2：日期范围选择器
```json
{
  "type": "FormItem",

    "valueFormat": "YYYY-MM-DD",
```

## 配置技巧

### 1. 性能优化
- 使用 `showWordLimit` 限制输入长度
- 使用 `clearable` 提升用户体验
- 使用 `filterable` 方便查找选项

### 2. 视觉统一
- 统一使用 `size: 'default'`
- 统一颜色主题
- 使用 `border` 增强视觉效果

### 3. 用户友好
- 提供清晰的 `placeholder`
- 使用 `prefixIcon`/`suffixIcon` 增强语义
- 使用 `showScore` 等属性提供反馈

### 4. 数据验证
- 设置 `maxlength` 防止过长输入
- 使用 `pattern` 进行格式验证
- 配置 `required` 确保必填
