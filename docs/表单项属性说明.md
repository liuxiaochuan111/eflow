## 属性配置特点

### 1. 完整性
- 每个组件都包含 Element Plus 官方文档中的所有属性
- 支持所有配置选项和类型

### 2. 分类清晰
- **基础属性** - 基本功能配置
- **显示属性** - 显示状态和布局
- **组件属性** - 组件特定配置
- **样式属性** - 自定义样式

### 3. 类型安全
- 所有属性都有明确的类型定义
- 支持 String、Number、Boolean、Array、Object 类型
- 自动验证属性值类型

### 4. 默认值
- 每个属性都有合理的默认值
- 符合 Element Plus 的默认行为
- 可以通过 `defaultOptions` 覆盖

### 5. 智能提示
- 每个属性都有中文标签
- 提供属性用途说明
- 显示属性类型信息

## 使用示例

### Input 输入框
```json
{
  "component": "Input",
  "options": {
    "placeholder": "请输入用户名",
    "clearable": true,
    "maxlength": 20,
    "showWordLimit": true,
    "prefixIcon": "User",
    "size": "default"
  }
}
```

### DatePicker 日期选择器
```json
{
  "component": "DatePicker",
  "options": {
    "type": "daterange",
    "format": "YYYY-MM-DD",
    "valueFormat": "YYYY-MM-DD",
    "startPlaceholder": "开始日期",
    "endPlaceholder": "结束日期",
    "clearable": true
  }
}
```

### Switch 开关
```json
{
  "component": "Switch",
  "options": {
    "activeText": "启用",
    "inactiveText": "禁用",
    "activeColor": "#13ce66",
    "inactiveColor": "#ff4949",
    "activeValue": "1",
    "inactiveValue": "0"
  }
}
```

## 注意事项

1. **选项数据格式**
   - Select、Radio、Checkbox 的 options 需要JSON格式
   - 例如：`[{"label": "选项1", "value": "1"}]`

2. **函数属性**
   - 部分属性需要函数名（如 disabledDate）
   - 函数需要在 customFuncs 中定义

3. **颜色格式**
   - 颜色属性支持十六进制（#409eff）
   - 也支持 RGB、HSL 等格式

4. **尺寸统一**
   - 所有组件的 size 选项一致
   - large / default / small

5. **类型转换**
   - InputNumber 组件自动处理数字类型
   - Switch 组件可自定义值类型

## 扩展性

如需添加新的表单项组件：

1. 在 `form-items.ts` 中添加配置
2. 定义所有可用属性
3. 配置事件和插槽
4. 更新组件注册

参考现有组件的配置格式即可。
